WWW
Es un sistema de información que permite acceder a documentos y recursos conectados a través de Internet.
HTML
Es un lenguaje de marcado que se utiliza para estructurar y presentar contenido en la web. Permite crear páginas web mediante el uso de etiquetas que definen elementos como encabezados, párrafos, imágenes, enlaces y formularios.
XML
Es un lenguaje de marcado que se utiliza para almacenar y transportar datos. Es ampliamente utilizado en la web para el intercambio de información entre diferentes sistemas.
